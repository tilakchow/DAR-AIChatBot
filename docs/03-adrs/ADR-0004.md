# ADR-0004: Fallback Strategy for Bot-Protected Static Fetching

- **Status:** Accepted
- **Date:** 2026-11-18
- **Deciders:** Tilak (Lead), AI Assistant
- **Consulted:** DAR-10, DAR-14, Risk R1

## Context and Problem Statement

DarGlobal (`darglobal.co.uk`) is protected by Imperva / Incapsula bot protection, and Wasalt (`wasalt.sa`) is protected by Cloudflare.
In accordance with DAR-14, an early test fetch of 5 DarGlobal URLs was conducted from the dev environment using `PoliteFetcher` with a plain HTTP client (`urllib.request`):

1. `https://darglobal.co.uk/` -> `BLOCKED` (HTTP 200, Incapsula challenge page detected)
2. `https://darglobal.co.uk/the-astera/` -> `BLOCKED` (HTTP 200, Incapsula challenge page detected)
3. `https://darglobal.co.uk/projects/` -> `BLOCKED` (HTTP 200, Incapsula challenge page detected)
4. `https://darglobal.co.uk/blog/` -> `BLOCKED` (HTTP 200, Incapsula challenge page detected)
5. `https://darglobal.co.uk/press/` -> `BLOCKED` (HTTP 200, Incapsula challenge page detected)

Wasalt (`https://wasalt.sa/en/villas-for-sale-in-riyadh`) was also probed with plain HTTP and returned a Cloudflare challenge page (`BLOCKED`).

Because `PoliteFetcher` accurately identified the challenge signatures, no challenge pages were indexed. However, a plain HTTP client cannot retrieve genuine page content from either target. This materialized **Risk R1**.

## Decision

We adopt **Option 1: Headless Browser with Playwright** as specified in the Project Plan mitigation for Risk R1.

### Verification Results (2026-11-18)
- Playwright with headless Chromium was initialized with a standard user-agent.
- **DarGlobal test:** `https://darglobal.co.uk/` yielded real DOM content with title: `"DarGlobal | International Luxury Real Estate Developer"` (282,964 bytes).
- **Wasalt test:** `https://wasalt.sa/en/villas-for-sale-in-riyadh` yielded real DOM content with title: `"Villas for Sale in Riyadh | Wasalt"` (924,691 bytes).

Both challenges resolved transparently.

## Consequences

- **Positive:** Scraper reliably accesses genuine JSON-LD, project facts, and listing offers from both sites.
- **Negative:** Crawl execution is heavier than plain HTTP requests. Rate limits (≥ 1.5s delay) and scoped category caps (DAR-11) will strictly prevent excessive load on target servers.
- **Implementation:** A `PlaywrightFetcher` will wrap Playwright sessions, honoring RFC 9309 robots rules, per-host polite delays, and Wasalt's non-commercial and no-PII policies.
