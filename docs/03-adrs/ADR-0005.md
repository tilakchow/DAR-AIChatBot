# ADR-0005: Cloud Hosting Platform Selection

- **Status:** Accepted
- **Date:** 2026-11-18
- **Deciders:** Tilak (Lead), AI Assistant
- **Consulted:** DAR-31, DAR-32, DAR-33, Risk R6

## Context and Problem Statement

The assignment's mandatory deliverable is a working public HTTPS URL where reviewers can interactively test the AI Property Assistant.
Requirements:
1. Running cost must be **$0** (NFR-06).
2. Must support running custom Docker containers.
3. Secret management must securely store `OPENROUTER_API_KEY` outside the repository and Docker image.
4. Minimal cold start / sleep latency to avoid failing initial reviewer requests (Risk R6).

## Comparison of Evaluated Platforms

| Criteria | 1. Hugging Face Spaces (Docker SDK) | 2. Render.com (Web Service) | 3. Fly.io |
|---|---|---|---|
| **Cost** | **$0** (Free CPU basic tier: 2 vCPU, 16GB RAM) | $0 (Free instance) | Free trial / requires CC verification |
| **Docker Support** | Native `Dockerfile` in repo root | Native `Dockerfile` | Native `fly.toml` + `Dockerfile` |
| **Sleep / Idle Behavior** | Sleeps after 48h of inactivity; wakes up in ~15-20s on first HTTP request | Sleeps after 15m of inactivity; cold start 50-90s | Scales to 0 by default; cold start ~5-10s |
| **Secret Management** | Encrypted repository Secrets dashboard | Environment variable dashboard | `fly secrets set` CLI |
| **Memory / CPU** | **16 GB RAM**, 2 vCPU | 512 MB RAM, 0.1 vCPU | 256 MB RAM |
| **Public HTTPS URL** | Automatic `https://*.hf.space` HTTPS domain with zero config | Automatic `https://*.onrender.com` HTTPS | Automatic `https://*.fly.dev` HTTPS |

## Decision

We select **Hugging Face Spaces (Docker SDK)** as the primary hosting platform, with **Render.com** as the secondary fallback.

### Rationale
1. **Zero Cost ($0):** Free CPU tier provides a generous 16GB RAM and 2 vCPUs at no charge.
2. **Generous Sleep Timeout:** Does not aggressively sleep every 15 minutes like Render, ensuring high availability during HR evaluation.
3. **Seamless Git Integration:** Pushing the git repository directly to Hugging Face triggers the Docker build and serves the app on standard port `7860`.
4. **Isolated Secret Store:** `OPENROUTER_API_KEY` is injected as an environment variable via Space Settings > Secrets.

## Consequences
- The Dockerfile exposes port `7860` by default to adhere to Hugging Face Spaces requirements.
- The README and runbook will document the live URL and wake-up verification steps.
