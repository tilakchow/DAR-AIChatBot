## 1. Purpose and Scope

This SRS defines every requirement for the DAR — DarGlobal AI Property Assistant. It is the single reference for what the system must, should, and may do. Each requirement carries:

- A stable ID (`FR-xx` for functional, `NFR-xx` for non-functional).
- An RFC 2119 keyword (MUST / SHOULD / MAY).
- A traceability link to a DAR issue and to the test case that verifies it.

## 2. Definitions

| Term | Definition |
|------|-----------|
| RAG | Retrieval-Augmented Generation — the pattern of retrieving relevant text chunks before calling an LLM. |
| Chunk | A unit of indexed text: a page segment, one FAQ pair, or one property listing. |
| Citation | A `[n]` reference in an answer that links to a source URL. |
| Challenge page | An HTML page served by Imperva or Cloudflare instead of real content, as a bot-protection measure. |
| Free tier | OpenRouter's offer of zero-cost model calls, limited to 50 requests/day for accounts with < $10 in credits. |
| Seller PII | Agent names, phone numbers, and WhatsApp links found in Wasalt listings. |

## 3. Functional Requirements

### 3.1 Data Collection

| ID | Requirement | DAR Issue | Test Case |
|----|-------------|-----------|-----------|
| FR-01 | The scraper MUST check each URL against the site's robots.txt with RFC 9309 wildcard support before fetching it. | DAR-8 | TC-01: robots checker unit tests |
| FR-02 | The scraper MUST enforce a minimum delay of ≥ 1.5 s between requests to the same host. | DAR-10 | TC-02: rate-limiting test |
| FR-03 | The scraper MUST retry HTTP 429 and 5xx responses at most 3 times with exponential backoff. | DAR-10 | TC-03: retry test |
| FR-04 | The scraper MUST detect Imperva and Cloudflare challenge pages and log them as `blocked`, not index them. | DAR-10 | TC-04: challenge detection test |
| FR-05 | The scraper MUST discover URLs from each site's sitemap(s), including gzip-compressed sitemaps. | DAR-9 | TC-05: sitemap parser test |
| FR-06 | The scraper MUST normalise sitemap URLs that contain spaces or XML entities (`&apos;`). | DAR-9 | TC-06: URL normalisation test |
| FR-07 | The scraper MUST NOT store Wasalt seller names, phone numbers, or WhatsApp links. | DAR-12, DAR-15 | TC-07: PII scrub test |
| FR-08 | The scraper MUST NOT fetch URLs disallowed by each site's robots.txt. | DAR-8 | TC-01 |
| FR-09 | The crawl MUST be limited to the URL groups and per-category caps defined in DAR-11. | DAR-11 | TC-08: scope test |
| FR-10 | The scraper MUST record a per-URL crawl log with outcomes: ok, blocked, robots-disallowed, http-error. | DAR-13 | TC-09: crawl log test |
